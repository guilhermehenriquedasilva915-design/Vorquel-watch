# Threat Model V1

## Protected assets

Local media, transcripts and provenance, the Supabase server credential, the
local filesystem, the processing environment, and human corrections.

## Attacker-controlled surfaces

Media bytes, captions, transcript text, embedded metadata, and — when URL
ingest arrives — remote metadata and redirects.

## Threats and control status

Status uses: **enforced** (implemented and verified), **partial** (implemented,
with a stated gap), **open** (not implemented).

| # | Threat | Control | Status |
|---|---|---|---|
| 1 | Stored prompt injection in transcript or metadata | `instruction_authority = NONE` enforced by CHECK constraints on every media-derived table; response envelope repeats it | enforced |
| 2 | Arbitrary local file access through a tool argument | No MCP tool accepts a path; identifiers validated against prefix and alphabet | enforced |
| 3 | Memory-safety exploit in the media parser | Parse runs in a separate process without the app's secrets; container and codec allowlist; AVI excluded | partial — process isolation, no resource or privilege confinement |
| 4 | Secret leakage through logs, MCP responses or config | Credential encrypted by DPAPI; explicit MCP projections; probe failures sanitized; Gitleaks in CI | partial — logging not yet structured or systematically redacted |
| 5 | Path traversal | Storage containment checks; credential names constrained; export paths confined | enforced |
| 6 | Command injection through subprocess | Explicit argv, `shell=False`, environment allowlist; CI policy check forbids `shell=True` and `os.system` | enforced |
| 7 | Cache poisoning, evidence misattribution | Objects re-hashed on reuse and before processing; mismatches quarantined with an incident record | enforced |
| 8 | Destruction of raw evidence or review history | Reviews append-only by trigger; `raw_text` never overwritten; runtime role holds no DELETE or TRUNCATE | enforced |
| 9 | Cross-source provenance corruption | Composite foreign keys tie every child row to its parent's source | enforced — verified 8/8 against the live project |
| 10 | A cancelled job being overwritten as succeeded | State-machine trigger; atomic completion behind a row lock | enforced — verified 11/11 |
| 11 | A dead worker stranding a job forever | Leases with heartbeats; expired leases reclaimable | enforced — verified 10/10 |
| 12 | Partial output presented as a final result | Reads resolve the producing job and refuse unless it succeeded | enforced |
| 13 | Silent model substitution | Models pinned to an exact upstream commit; unpinned models refused; provenance records repository, revision and runtime versions | enforced |
| 14 | Supply-chain compromise via dependencies | Hash-pinned lock, `--require-hashes` install, lock-drift check, `pip-audit`, SBOM | enforced |
| 15 | Supply-chain compromise via GitHub Actions | Pinned by commit SHA, checked by a CI policy script | enforced |
| 16 | Unbounded processing causing resource exhaustion | Size and duration limits; probe timeout; capped probe output; bounded MCP pagination | partial — no memory, CPU, disk quota or concurrency limits |
| 17 | Over-privileged database access | `watch_runtime` holds no DELETE, TRUNCATE, TRIGGER or REFERENCES; `anon` and `authenticated` have no access | partial — role provisioned but the runtime still uses `service_role` |
| 18 | Unauthorized change to `main` | Branch protection | open — requires GitHub authentication |
| 19 | SSRF when URL ingest is added | — | open — URL ingest is out of scope for V1 |

## Assumptions

- The operator's Windows account is not already compromised. DPAPI protects the
  credential from other accounts and other machines, not from code running as
  this user.
- Claude Desktop is trusted to invoke tools; it is not trusted to be immune to
  prompt injection, which is why the tool surface contains nothing dangerous to
  invoke.
- The Supabase project is reachable and its access controls hold.

## Explicitly out of scope for V1

Remote MCP, URL ingest, raw media upload, browser cookie access, voice identity
or biometric recognition, and autonomous action on the operator's behalf.
