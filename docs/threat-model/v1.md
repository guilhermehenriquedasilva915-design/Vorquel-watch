# Threat Model V1

## Protected assets

- local media
- transcripts and provenance
- Supabase server credentials
- local filesystem
- processing environment
- user corrections/reviews

## Primary attacker-controlled surfaces

Media bytes, captions, transcript text, embedded metadata, future OCR/frame text and future URL metadata.

## Main threats

1. Stored prompt injection in transcript or metadata.
2. Arbitrary local file access through a tool argument.
3. SSRF when URL ingest is added.
4. Secret leakage through logs, MCP responses or frontend bundles.
5. Path traversal or unsafe archive extraction.
6. Command injection through subprocess invocation.
7. Cache poisoning or evidence misattribution.
8. Mutation/destruction of raw evidence or review history.
9. Unbounded processing causing resource exhaustion.
10. Supply-chain compromise through dependencies or GitHub Actions.

## Baseline controls

- data/instruction authority separation;
- opaque source IDs;
- no raw path or URL MCP inputs in V1;
- subprocess argv only, no shell execution;
- content SHA-256 identity;
- append-only reviews;
- structured provenance;
- controlled local workspace;
- cloud DB stores no host paths;
- SHA-pinned GitHub Actions;
- secret scanning;
- adversarial boundary tests.
